## Impact analysis — choose proportional path

Lightweight: changed behavior/responsibility; existing owner; affected consumers/contracts/data/safeguards; new or competing responsibility; focused evidence. Escalate if broader impact emerges.

Standard/high impact: complete the Integration Map. For new projects state absent owners/contracts explicitly.

| Responsibility | Existing owner / concrete references | Treatment / justified new responsibility and dependency direction | Consumers | Preserved or approved changed contracts | Safeguards | Verification |
|---|---|---|---|---|---|---|

Explain relevant omitted layers. If derived data/effects exist, record source/identity, write/effect owner, transaction/sync, replay/retry and duplicate/divergence prevention.
