# Completion / milestone report

Follow [verification and delivery](../references/verification-and-delivery.md), [canonical CAI](../references/architecture-and-planning.md), and [authorization](../references/records-and-authorization.md). Reuse the project's report format. Include only relevant fields; templates do not create additional gates or delivery permission.

## Lightweight path

Use a short paragraph or a few bullets:

- Outcome and accepted boundary; actual change/owner and affected compatibility; concise mandatory drift comparison against approved design and relevant decisions.
- Applicable verification: new runs or retained evidence, tested revision and reuse reason, limitations.
- Any required blocker or remaining action; optional improvements explicitly deferred.

## Expanded path when impact or project policy requires it

- Initiative / approved plan / final revision and actual work state.
- Actual changes, approved decisions, ownership/contracts/safeguards preserved or changed.
- Integration Map reconciliation: planned treatment versus actual changes; affected consumers; required evidence; remaining integration risks.
- Readiness and drift evidence: compared baseline/decision references, findings with file/artifact support, compatible details, covered repairs, deferred work and any significant deviation's original approval or unresolved gate.
- Optional review choice/outcome when relevant, actual reviewer count/remits/context limits, and consolidated findings; distinguish skipped/pending/unverified from performed independent review.
- Relevant documentation reconciliation and supersession.
- Delivery/operational operations actually covered, performed or blocked, each distinguished truthfully.
- Required remaining work and next permitted action; useful learning without duplicating decisions.

Do not claim required integration succeeded because feature-only tests passed. Presidential presentation can use an executive briefing with recommendation/impact/decision where needed; it does not require longer output or repeated titles.
